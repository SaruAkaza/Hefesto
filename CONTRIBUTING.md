# Contribuições

Abra uma issue com passos reproduzíveis e dados fictícios. Pull requests devem explicar o comportamento alterado e os testes executados.

Use Node.js 22.13 ou superior, instale com `npm ci --prefix server` e execute `npm run ci`.

Preserve leituras históricas, trilhas de auditoria e equipamentos aposentados. Nunca trate valores desconhecidos como zero. Comandos externos devem usar argumentos separados, validação e timeout.

Não inclua dados de instalações reais, nomes de organizações, inventários, IPs internos, números de série, contratos, logos, credenciais ou relatórios operacionais. Use dados sintéticos e endereços reservados nos exemplos e testes.

As contribuições para uma versão publicada sob MIT também devem ser licenciáveis sob MIT. Dependências de terceiros mantêm seus próprios avisos e licenças.
