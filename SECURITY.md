# Segurança

Use o painel em uma rede administrada, com TLS e controle de acesso na implantação. Configure credenciais próprias e segredos aleatórios. Faça varreduras somente em redes que você pode administrar.

Não publique vulnerabilidades acompanhadas de tokens, bancos, dados de instalações reais ou evidências identificáveis. Ao reportar um problema, forneça uma reprodução mínima com dados sintéticos.

O repositório deve conter apenas código e exemplos genéricos. Bancos, logs, configurações, inventários, evidências de impressoras e pacotes de implantação são locais.
